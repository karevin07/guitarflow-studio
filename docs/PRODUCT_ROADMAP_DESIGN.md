# 功能範圍

目前以歌曲創作、練習和曲庫功能為主，支援以下操作：

- 創作：六線譜、歌詞與和弦編輯，段落管理、快捷鍵及自動儲存。
- 練習：播放、循環、節拍器、伴奏 pattern、轉調與 capo。
- 和弦：搜尋、替代指法、音符辨識與整首指法規劃。
- 編曲：調性分析與單音 solo 建議。
- 曲庫：歌曲資訊、標籤、收藏、歌單與播放順序。
- 檔案：`.gflow` 與和弦譜匯入，MIDI／MusicXML 匯出，Google Drive 歌曲備份。

Guitar Pro 和 MusicXML 匯入已在 2026-10-03 移除，仍可匯出 MusicXML。

使用方式在 [README](../README.md)，實作上的取捨則寫在[設計說明](DESIGN.md)。
