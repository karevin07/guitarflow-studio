# 產品方向

GuitarFlow 以自己的 `.gflow` 格式處理吉他創作與練習。架構與操作方式見 [README](../README.md)；此文件只列產品範圍與待評估事項。

## 現有範圍

- 創作：六線譜、歌詞與和弦編輯，段落管理、快捷鍵及自動儲存。
- 練習：播放、循環、節拍器、伴奏 pattern、轉調與 capo 顯示。
- 和弦：搜尋、替代指法、音符辨識與整首歌的指法規劃。
- 編曲：調性分析與單音 solo 建議。
- 曲庫：帳號隔離、歌曲資訊、標籤、收藏、歌單與播放順序。
- 資料移轉：`.gflow`、貼上和弦譜、Google Drive 備份與還原；MIDI 與 MusicXML 匯出。

## 待評估

- 正式部署：HTTPS、正式應用伺服器、登入保護與資料備份。
- 舊資料歸屬：公開服務前處理沒有擁有者的歌曲及認領機制。
- 記譜模型：是否從固定格線改為音符時值模型；會影響編輯、播放與匯出。
- 樂譜呈現：評估 SVG 排版，改善不同螢幕尺寸的閱讀體驗。
- 核心流程品質：持續驗證存檔、播放、匯入匯出與手機操作。

以上尚未排定時程。
