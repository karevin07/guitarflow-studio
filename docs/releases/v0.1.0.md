GuitarFlow Studio 第一個公開版本：網頁版吉他創作與練習工具，React + TypeScript 前端、Django REST Framework 後端。

![歌曲庫](https://raw.githubusercontent.com/karevin07/guitarflow-studio/v0.1.0/docs/images/library.png)

## 功能

- **創作**：六線譜與歌詞編輯、段落管理、和弦辨識、Undo/Redo、自動儲存
- **練習**：播放、節拍器、A–B 循環、轉調與 capo、伴奏 pattern、整首歌的指法配置、依音域建議調性
- **編曲**：依調性與和弦進行產生單音 solo
- **曲庫**：搜尋、標籤、收藏、歌單與演奏順序
- **檔案**：匯入 `.gflow`、貼上和弦譜；匯出 `.gflow`、MIDI、MusicXML
- **Google Drive**：單首上傳、整庫備份與還原（需自行設定 OAuth 用戶端 ID）

## 設計重點

- 曲庫資訊走獨立的 `PATCH /songs/{id}/info/`，自動儲存不會覆蓋曲庫的修改
- 巢狀資料以差異更新保留 ID，整首歌在同一個資料庫交易中寫入
- 登入狀態確認前的操作會排隊，確認後自動繼續
- Google Drive 只在瀏覽器端串接，使用 `drive.file` 權限，後端不經手 Google 憑證
- 指法以回溯搜尋產生，整首配置以動態規劃找出總成本最低的組合

詳見 [README](https://github.com/karevin07/guitarflow-studio/blob/v0.1.0/README.md) 與[設計說明](https://github.com/karevin07/guitarflow-studio/blob/v0.1.0/docs/DESIGN.md)。

## 啟動

```bash
make docker
```

開啟 <http://localhost:3003>。目前的 Compose 是開發配置，不適合直接對外提供服務。
